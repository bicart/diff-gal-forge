# License, assets, and legal boundaries

> This is a plain-language engineering note, not legal advice. If you plan to
> distribute assets or run a commercial service, consult a lawyer in your
> jurisdiction.

## Code

The plugin code is released under the **MIT License** (see `LICENSE`). You may
use, modify, redistribute, and sell it, provided the copyright notice and
permission notice are kept.

Letting users modify the plugin is therefore **not** a legal problem by itself —
it is the point of an open-source license. The risks worth managing are about
*content* and *conduct*, not about forking.

## Example artwork

`examples/demo/` is generated by `scripts/make-demo-pack.mjs` from geometric
primitives; it contains no third-party artwork.

`examples/aria/` was produced on the maintainer's machine with a local image
model (OpenVINO + Animagine XL 4.0) and edited with masked inpainting. The model
weights are **not** redistributed here — only the generated PNGs. The generation
recipe is documented in `docs/ai-art.md`.

Both packs are released under **CC0-1.0** (public domain dedication) so they can
be copied, modified, and redistributed freely. Art you add yourself keeps
whatever terms you choose; the plugin does not care.

## What this repository deliberately does not contain

- No commercial game sprites, CGs, backgrounds, voice files, or scripts.
- No game names, character names, logos, or trademarks as branding.
- No parser for a proprietary game format.
- No decryption, unpacking, DRM circumvention, or "technical protection measure"
  bypass.
- No bundled assets from any title.

The plugin reads ordinary PNG files and ordinary JSON. That is the whole input
surface.

## What users are responsible for

Diff Forge is a **bring-your-own-assets** tool. If you put images into `packs/`,
you are responsible for having the rights to use them. In particular:

- Do not redistribute extracted assets from a commercial game.
- Do not publish packs that contain third-party character art without permission.
- Do not use a game's name or character names to promote your fork or your packs.

A tool can be neutral while a particular pack is infringing. Keep the two
separate: publish code and original examples, keep personal assets local.

## Why "AI writes data" is also a legal choice

The plugin does not accept AI-generated code, shell commands, or install steps.
It accepts JSON that is validated against a small schema. This keeps the
attack surface small and keeps the repository free of game-specific logic that
would be harder to defend.

## Reporting

If you believe content in this repository infringes your rights, open an issue
(or contact the maintainer listed in `package.json`) with the specific file and
the basis of the claim. Content that cannot be justified will be removed.
